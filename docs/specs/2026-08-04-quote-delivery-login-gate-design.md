# 견적서 받기 로그인 게이트 설계

- 작성일: 2026-08-04
- 대상: `/quote` 견적 결과 화면의 「카카오톡으로 견적서 받기」 버튼

## 배경

현재 「카카오톡으로 견적서 받기」는 로그인 여부를 확인하지 않는다. 비회원이 눌러도
견적이 저장되고, 요청 문구가 복사되고, 카카오 채널 대화창이 열린다.

이 동작은 `NEXT_PUBLIC_KAKAO_QUOTE_AUTO_SEND` 가 꺼져 있을 때의 임시 경로
(`channelTalkDelivery`)에서 발생한다. 자동발송 경로(`kakaoDeliveryEnabled`)는 이미
로그인을 요구하지만, 운영에는 해당 플래그가 없어 항상 임시 경로로 동작한다.

개발 요청사로부터 "로그인 없이 견적서가 전달되는 것 같다"는 문의가 접수되었고,
정책상 **견적서 수령 시점에는 로그인을 필수**로 두기로 했다.

## 목표

비로그인 상태에서 「카카오톡으로 견적서 받기」를 누르면 카카오 로그인을 먼저 거치게
한다. 로그인 후에는 입력했던 견적이 복원된 상태에서 요청 흐름이 이어져야 한다.

## 비목표

- 견적 계산·저장 자체를 회원 전용으로 바꾸지 않는다. 비회원도 견적은 볼 수 있다.
- 「상담하기」(채널톡) 버튼은 로그인 무관하게 유지한다. 단순 문의까지 막으면 이탈만 는다.
- 자동발송 경로(`kakaoDeliveryEnabled`)의 동작은 변경하지 않는다. 이미 로그인 필수다.
- 「심사 요청하기」는 이미 로그인 게이트가 있으므로 손대지 않는다.

## 흐름

```
[카카오톡으로 견적서 받기]
   ├─ 로그인됨  → 견적 저장 → 문구 복사 → 안내 모달 → (CTA) 카카오 채널 대화창
   └─ 비로그인  → 견적 상태 보관 → 「로그인이 필요해요」 모달
                     └─ [카카오 로그인] → 카카오 인증 → /quote 복귀
                            └─ 견적 자동 복원 + 안내 모달 자동 표시
                                   └─ (CTA) 카카오 채널 대화창
```

로그인 복귀 직후에 대화창을 자동으로 열지 않는다. 페이지 로드 직후의 `window.open` 은
팝업 차단에 걸린다(커밋 `0f9e237` 에서 고쳤던 문제). 안내 모달까지만 자동으로 띄우고,
대화창은 모달 CTA 클릭이라는 사용자 제스처로 연다.

## 변경 대상

| 파일 | 변경 |
| --- | --- |
| `src/app/(public)/quote/QuoteClientPageV2.tsx` | 세션 체크 · 로그인 게이트 모달 상태 · 복귀 후 1회 자동 재개 |
| `src/components/quote/LoginRequiredModal.tsx` | 미사용 컴포넌트를 재사용. 문구를 prop 으로 주입 가능하게 변경 |

새 컴포넌트는 만들지 않는다. 로그인 리다이렉트는 기존 `startKakaoConsentFlow()` 를
그대로 쓴다 — 견적 상태를 localStorage 에 저장한 뒤 카카오 인증으로 보낸다.

### LoginRequiredModal

현재 문구가 "견적서 이미지 다운로드는 회원만 이용할 수 있어요"로 고정되어 있다.
`description` 을 선택적 prop 으로 받아 호출부가 문구를 주입하도록 바꾸고, 기존 문구를
기본값으로 남긴다. 그 외 마크업·스타일은 유지한다.

### 자동 재개

로그인 이동 시 복귀 주소에 `deliver=1` 표식을 붙인다. 복귀 후 아래 조건이 모두 참일 때
1회만 요청 흐름을 자동 실행한다.

- URL 에 `deliver=1` 이 있다
- 견적 복원이 끝났다 (`quoteResult` 존재)
- 세션이 실제로 있다

실행 직후 `deliver` 파라미터를 URL 에서 제거하고, 재실행 방지 ref 로 이중 실행을 막는다.
기존 restore 마커 동기화 effect 가 쿼리를 다시 쓰므로, 그 effect 와 순서가 엉키지 않도록
소비 시점에 명시적으로 제거한다.

## 에러 처리

- 세션 조회 자체가 실패하면 비로그인으로 간주하고 게이트를 띄운다. 인증 오류 시 통과시키지 않는다.
- 로그인 후에도 세션이 없으면 자동 재개하지 않는다. 고객이 버튼을 다시 누르면 게이트가 다시 뜬다.
- 채널 ID 미설정 등 기존 에러 처리는 그대로 유지한다.

## 테스트

`src/app/(public)/quote/QuoteClientPageV2.test.tsx` 에 추가한다.

1. 비로그인 + 견적서 받기 클릭 → 로그인 게이트 모달이 뜨고, 견적 저장 API 와 채널 대화창이 호출되지 않는다
2. 로그인 게이트 모달의 카카오 로그인 클릭 → `startKakaoLogin` 이 `deliver=1` 을 포함한 복귀 주소로 호출된다
3. 로그인 상태 + 견적서 받기 클릭 → 기존 흐름(견적 저장 → 문구 복사 → 안내 모달)이 그대로 동작한다
4. `deliver=1` + 로그인 상태로 복귀 → 안내 모달이 자동으로 뜨고, 대화창은 자동으로 열리지 않는다

## 참고

  집어 써서 러너가 기동하지 못한다.
